1 · Create your bot

Pennywise never ships a shared bot — each user creates their own. The token stays on this machine.

  1. Open Telegram and search for @BotFather.
  2. Send /newbot and follow the prompts:
    • Name — shown in chats, e.g. My Pennywise
    • Username — globally unique, must end in bot, e.g. arthur_pennywise_bot
  3. Copy the API token BotFather sends you (it looks like 1234567890:AA…).
  4. Paste it below.
