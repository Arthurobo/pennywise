# Code of Conduct

We follow the [Contributor Covenant v2.1][cov]. In short: be respectful,
assume good faith, and disagree without making it personal.

Report concerns to the project maintainer at the email listed in
[`README.md`](README.md), or open a private security advisory on GitHub for
sensitive matters.

[cov]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
